# Customer Churn Flagship Project - 62K Users

End-to-End Data Analytics | Excel + SQL + Python + Power BI

## Overview
Analyzed 62,000+ telecom customers to predict churn, reduce attrition, and build retention strategy.

## Tech Stack
- Excel: Data Cleaning, Pivot, VLOOKUP, Charts
- SQL: Joins, CTEs, Window Functions, Churn Segmentation  
- Python: Pandas, EDA, Logistic Regression, Random Forest (ROC-AUC 0.89)
- Power BI: DAX, RLS (Row Level Security), Interactive Dashboard

## Business Impact
- Identified 27% churn risk in high-value segment
- Proposed retention saving $1.2M annually

## Folders Structure
- /excel - cleaned data + dashboards
- /sql - queries  
- /python - jupyter notebook + model
- /powerbi - .pbix dashboard + RLS screenshots
